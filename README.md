# Car Show Registration System

A web-based Car Show Registration System developed for Integrative Programming 2. The project manages car show registrations, participant information, registration status, and payment records.

## Technologies Used

### Frontend
- React JS
- Vite
- Tailwind CSS

### Backend
- C# / .NET 10
- Entity Framework Core
- SQLite
- FluentValidation
- Scalar API

## Running the Frontend

1. Open a terminal.
2. Navigate to the frontend folder:

   `cd frontend`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

## Development Status

The frontend currently uses sample registration data while backend development and API integration are in progress.

The frontend will connect to the backend API when the endpoints are ready.
